# SHORTS 예약 회차 잠금·최신 SHA 규약

목적: 여러 예약 회차가 같은 파일을 동시에 고쳐 서로의 커밋을 덮어쓰는 일(실제로 LF-031/032가 한 번 사라졌음)을 막는다.

1. 시작: 잠금 파일 memory/routines/_reorg_20261128/shorts.lock 을 확인한다. 있고 수정 시각이 20분 이내면 이번 회차는 쓰기 작업을 하지 않고 조회·기록만 한다. 20분을 넘겼으면 오래된 잠금으로 보고 덮어쓴다.
2. 쓰기 직전: 회차 ID와 시각을 JSON으로 잠금 파일에 쓴다(없으면 만든다). 만들거나 쓰기에 실패하면 쓰기 작업을 하지 않고 오류를 shorts_state.md에 기록한다.
3. 업로드 전: GitHub 커밋 화면에서 최신 main SHA를 확인하고, 그 SHA 고정 raw 주소로 받은 파일 위에 자기 변경만 적용한다. 업로드 직전에 SHA가 바뀌었으면 다시 받는다.
4. 통파일 업로드 대신 /upload/main 에 파일을 올리고 새 브랜치 PR로 병합한다. 웹 편집기 붙여넣기는 파일을 불리므로 쓰지 않는다.
5. 끝: 잠금 파일을 삭제한다. 삭제 오류가 나면 내용을 {"released":true}로 덮어쓰고 shorts_state.md에 적는다.
6. 사용자 설정(즐겨찾기·저장 조합·첫 화면·메뉴 설정)은 어떤 시험에서도 지우지 않는다. 시험은 임시 브라우저 저장소를 쓰는 번들 페이지에서 하고, 공개 페이지 시험은 읽기·클릭만 한다.
